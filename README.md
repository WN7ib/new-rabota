# New.работа

Работа, подработка и стажировки для молодёжи от 14 лет по всей России и удалённо.

- `index.html`, `app.js` — сайт для всех
- `admin.html` — модерация: вакансии появляются на сайте только после одобрения
- `config.js` — адрес базы и публичный ключ
- `schema.sql` — таблица и правила доступа для Supabase

## 1. База (Supabase, бесплатно)

1. Зарегистрируйся на https://supabase.com → New project. Регион: Frankfurt (eu-central-1), он ближе всего к России.
2. SQL Editor → New query → вставь весь `schema.sql` → Run.
3. Project Settings → API: скопируй **Project URL** и **anon public key** в `config.js`.
4. Открой `admin.html` на сайте, введи почту и пароль → «Создать аккаунт модератора» → подтверди почту по письму.
5. В SQL Editor выполни последнюю строку из `schema.sql` со своей почтой. Теперь ты модератор.
6. Authentication → Sign In / Providers → выключи «Allow new users to sign up», чтобы чужие не создавали аккаунты.

## 2. Сайт (GitHub Pages, бесплатно)

1. На GitHub создай пустой репозиторий `new-rabota` (Public).
2. Залей туда эти файлы (или дай доступ Claude, он зальёт сам).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт откроется по адресу `https://wn7ib.github.io/new-rabota/`.

## 3. Свой домен и DNS

**Домен** — это имя сайта (например `newrabota.ru`). **DNS** — записи у регистратора, которые говорят интернету: «это имя ведёт на серверы GitHub».

1. Купи домен у регистратора: reg.ru, nic.ru, Timeweb (`.ru` около 200–900 ₽ в год).
2. В панели регистратора открой «DNS-записи» / «Управление зоной» и добавь:

| Тип   | Имя (хост) | Значение          |
|-------|-----------|-------------------|
| A     | @         | 185.199.108.153   |
| A     | @         | 185.199.109.153   |
| A     | @         | 185.199.110.153   |
| A     | @         | 185.199.111.153   |
| CNAME | www       | wn7ib.github.io.  |

   Старые A-записи для `@` (если регистратор поставил свои) удали.
3. GitHub → репозиторий → Settings → Pages → Custom domain: впиши домен → Save. GitHub сам создаст файл `CNAME`.
4. Подожди от 15 минут до суток, пока записи разойдутся. Потом поставь галочку **Enforce HTTPS**.

Поддомен у существующего сайта (например `rabota.novye.site`): одна запись `CNAME`, имя `rabota`, значение `wn7ib.github.io.` и тот же шаг 3.
